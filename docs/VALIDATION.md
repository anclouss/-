# Проверки сборки — 1 ноября 2026

## Выполнено

- `.venv/bin/python -m pytest -q`: **55 passed, 3 subtests passed**, 32,03 секунды. В этой облачной среде TestClient запускается с разрешением исполнения вне сетевой песочницы: внутри неё зависает пробуждение тестового потока.
- `bash scripts/cloud-install.sh`: повторная установка строго зафиксированных Python/npm-зависимостей и production-сборка прошли. Проверены импорт faster-whisper и загрузка приложения FastAPI. Зафиксированные зависимости требуют Python 3.12.
- Реальный FFmpeg: извлечение PCM16 mono16k, 1080×1920 H.264/AAC, crop/fit/split, субтитры с подсветкой, сокращение тихих пауз, повторный экспорт. Тестовые файлы создаются во временных каталогах.
- Сквозной интеграционный тест: HTTP-загрузка настоящего видео → SQLite-очередь → восстановление прерванного задания → аудиосигналы → проверка кандидатов → FFmpeg → скачивание MP4 → изменение клипа → новый MP4 → ZIP. **Транскрипция и ответы LLM в этом тесте подменяются контролируемыми данными**. Сам FFmpeg, база, API и алгоритм валидации исполняются реально.
- API: границы/текст/оформление редактора, одновременные запросы экспорта, Range-запросы, ZIP только выбранного проекта, ошибки и повтор обработки, безопасная очистка источников с сохранением экспортов, отклонение сторонних URL и Host/Origin.
- Реальный Chromium: все шесть страниц и контракты интерфейса, загрузка, polling, настройки, редактор, скачивание, мобильная ширина390px и desktop1440px. Для страниц с результатами использовались явно заданные API-фикстуры, а не вывод моделей.
- Production frontend + настоящий API, без подмены ответов: пустая библиотека проектов, страница настроек и фактические статусы зависимостей, форма загрузки, без JS-исключений.
- Bash-launcher: старт API+worker+Vite на отдельной базе, HTTP200 напрямую и через прокси; после остановки завершены только его дочерние процессы, порты освобождены.

## Не подтверждено

- Настоящее распознавание речи и смысловой отбор LLM: запрос к официальной модели Hugging Face был отклонён прокси среды с HTTP403. Ollama и её модель в текущей машине не установлены; OpenAI API-ключ не задан. Установленный Python-пакет faster-whisper не означает, что загружены веса.
- Сквозной импорт реальной записи YouTube/Twitch: без конкретной записи и разрешённых сетевых назначений он не выполнялся. Обновлённый yt-dlp установлен с официальными default-зависимостями и использует Node для JS-компонентов. Изменения сайтов, авторизация и региональные ограничения могут препятствовать импорту; ручная загрузка файла остаётся основным путём.
- Windows/PowerShell-launcher: подготовлен, но в Linux без PowerShell не выполнялся.
- Покадровое слежение, понимание событий игры/чата и гарантированная вирусность не заявляются. Поиск лица в MVP — редкие локальные выборки и стабильный центр, zoom — плавное движение, а не распознавание эмоции.
- Нагрузочный прогон многочасовой записи и оценка качества на пользовательских стримах ещё не выполнены.

## Дополнение: диагностика локального Whisper

Исправлена потеря причины ошибок: импорт, подготовка модели и распознавание получают отдельные коды `STT_*`. Добавлены проверка Windows-библиотек в launcher и `Проверить распознавание.cmd` (с поддержкой перетаскивания видео). При подтверждённом сбое загрузки DLL launcher пытается установить официальный Microsoft Visual C++ Redistributable x64; это не считается установленной причиной любого сбоя.

Проверено: **89 tests passed, 3 subtests passed**; 34 новые проверки охватывают причины ошибок, ленивый сбой VAD, отсутствие незаметного fallback и исключение секретов/подписанных URL из сообщений. Нативные импорты CTranslate2, ONNX Runtime и faster-whisper прошли на Linux; PowerShell-грамматика прошла. Windows-исполнение не проверено.

Попытка настоящего распознавания короткой речи моделью tiny в текущей облачной среде остановилась на загрузке весов. Безопасная HTTP-проверка показала перенаправление с huggingface.co на новый домен us.aws.cdn.hf.co и HTTP403 от политики прокси этого облачного экземпляра. Это **не устанавливает причину на компьютере пользователя**. Сетевая конфигурация и публикация среды в рамках этого исправления не менялись; реальное локальное распознавание здесь остаётся неподтверждённым.
