# ClipForge

Локальное веб-приложение для превращения длинных записей стримов в вертикальные клипы: загрузка, транскрипция, поиск моментов, субтитры с подсветкой слов, редактор и экспорт MP4. Интерфейс — на русском, в тёмной теме.

Это рабочая основа для одного пользователя. Качество отбора зависит от транскрипции, модели анализа и содержания записи; Viral Score не предсказывает количество просмотров. Приложение не содержит аккаунтов, биллинга и распределённой очереди.

## Возможности

- Локальный файл или ссылка на публичную запись YouTube/Twitch. Обработка выполняется отдельным воркером и продолжается после закрытия браузера.
- Проекты и очередь заданий сохраняются в SQLite. После перезапуска воркер повторно подхватывает прерванные задания.
- Транскрипция `faster-whisper` локально либо Whisper через OpenAI API; временные метки на уровне слов.
- Семантический анализ через Ollama или OpenAI, перекрывающиеся фрагменты, уточнение границ, устранение повторяющихся кандидатов и рейтинг.
- Экспорт 1080×1920, H.264/AAC, нормализация звука, вертикальный crop, вписывание и разделённый экран «камера + игра».
- Субтитры, настройка оформления, изменение диапазона, кадрирования и текста, повторный экспорт; скачивание одного MP4 или ZIP с выбранными/всеми клипами.
- Очистка старых исходников завершённых и неудачных проектов по сроку хранения. Готовые экспорты и транскрипты сохраняются.

Подробности архитектуры, ограничений и следующего этапа: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Требования

- Python 3.12, Node.js 22/24 и npm. Зафиксированные Python-зависимости требуют 3.12.
- FFmpeg и FFprobe в `PATH`; FFmpeg должен поддерживать `libx264`, `aac`, `ass`/`libass` и `loudnorm`.
- Для локального AI: доступ в интернет для первой загрузки Whisper и Ollama-модели. Далее скачанные модели могут работать без платных API.
- Рекомендуется 16 ГБ RAM для локальной модели 7B; при меньшем объёме используйте более компактную Ollama-модель или платный API. Видеофайлы, временное аудио, модели и клипы требуют свободного места на диске.

На CPU обработка длинного видео может занимать дольше его длительности. Для первого запуска разумно взять запись на 2–5 минут. Ограничение загрузки по умолчанию — 4 ГБ, а импорта по ссылке — до 12 часов; доступное место всё равно нужно контролировать.

## Запуск на Windows

### Одной кнопкой

Распакуйте весь проект в обычную папку и дважды щёлкните **`Запустить ClipForge.cmd`** в её корне. Не запускайте файл внутри ZIP и не переносите его отдельно от проекта.

При первом запуске сценарий проверит Python 3.12, Node.js и FFmpeg; недостающие инструменты установит через официальный каталог `winget`. Затем создаст `.venv`, установит зафиксированные зависимости, соберёт интерфейс и создаст `.env`, только если файла ещё нет. Существующие настройки и видео сохраняются. Windows может показать обычный запрос разрешения на установку. Если `winget` недоступен, установите инструменты вручную по инструкции ниже.

Если в действующих настройках выбран локальный анализ, сценарий проверит Ollama, при необходимости установит и запустит её, загрузит выбранную модель. Первая загрузка может занимать несколько гигабайт и продолжительное время. Модель Whisper автоматически загружается при обработке первого видео. При выборе OpenAI нужен собственный ключ в `.env`; сценарий не создаёт ключи и не переключает AI-режим без вашего участия. Для удалённого сервера Ollama установка модели выполняется на том сервере.

После проверки готовности откроется браузер. **Оставьте окно запуска открытым; для остановки нажмите `Ctrl+C`.** Сценарий останавливает только запущенные им процессы, не завершает уже работавшую службу Ollama. Повторный щелчок открывает действующий экземпляр вместо запуска второго воркера. Интерфейс обслуживает сам FastAPI, отдельный Vite-сервер не нужен. Порт берётся из `.env` (по умолчанию 8000); поддерживается только локальный доступ `127.0.0.1` / `localhost`.

При следующих запусках зависимости и сборка используются повторно, пока соответствующие файлы проекта не изменились. Ошибка остаётся в окне; логи находятся в `.logs`. Для принудительного восстановления установки удалите только `.venv/clipforge-requirements.sha256`, `frontend/node_modules/.clipforge-lock.sha256` и `frontend/dist/.clipforge-build.sha256`, затем запустите кнопку снова. Не удаляйте `data` и `.env`.

CMD разрешает выполнение PowerShell-сценария только в дочернем процессе (`ExecutionPolicy Bypass`), не меняя системную политику. Политики организации сохраняют приоритет: если они блокируют запуск, используйте разрешённый администратором способ и ручные команды ниже. Синтаксис сценария проверяется в Linux; настоящий Windows-запуск в этой среде не выполнялся.

### Ручная установка

Откройте PowerShell в корне **существующего checkout** проекта. Дополнительный Git worktree не нужен.

1. Установите инструменты, если их ещё нет:

   ```powershell
   winget install --id Python.Python.3.12 -e
   winget install --id OpenJS.NodeJS.LTS -e
   winget install --id Gyan.FFmpeg -e
   winget install --id Ollama.Ollama -e
   ```

   Откройте новое окно PowerShell после установки и проверьте:

   ```powershell
   py -3.12 --version
   node --version
   npm --version
   ffmpeg -version
   ffprobe -version
   ```

2. Создайте окружение и установите зависимости. Активация PowerShell-окружения не обязательна:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
   npm.cmd ci --prefix frontend
   if (-not (Test-Path .env)) { Copy-Item .env.example .env }
   ```

3. Подготовьте AI. Для локального режима запустите приложение Ollama и загрузите модель:

   ```powershell
   ollama pull qwen2.5:7b
   ollama list
   ```

   Whisper `small` загрузится при первой транскрипции; загрузка может занять время. Если Ollama не запущена как приложение/служба, в отдельном терминале выполните `ollama serve`.

4. Запустите API, воркер и frontend:

   ```powershell
   .\scripts\start.ps1
   ```

   Скрипт читает `HOST`/`PORT` из `.env`, сохраняет логи в `.logs`, проверяет HTTP-доступность API и frontend. Откройте адрес frontend, который выведен в терминале (по умолчанию `http://127.0.0.1:5173`). `Ctrl+C` останавливает только процессы, запущенные скриптом. Если корпоративная политика запрещает PowerShell-скрипты, используйте ручной запуск ниже, а не меняйте политику организации.

5. В интерфейсе откройте «Загрузить», добавьте запись, дождитесь результатов. В редакторе сохраните изменения повторным экспортом; скачивание снова станет доступно после его завершения.

### Ручной запуск: три терминала

В каждом терминале рабочий каталог — корень репозитория:

```powershell
# Терминал 1: API
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

```powershell
# Терминал 2: единственный воркер
.\.venv\Scripts\python.exe -m backend.app.worker
```

```powershell
# Терминал 3: интерфейс разработки
npm.cmd --prefix frontend run dev -- --host 127.0.0.1
```

Если меняете порт API при ручном запуске, задайте `VITE_API_PROXY_TARGET` для frontend, например `$env:VITE_API_PROXY_TARGET="http://127.0.0.1:8001"`.

## Linux / macOS

Установите Python, Node.js и FFmpeg средствами вашей ОС, затем в корне checkout:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
test -f .env || cp .env.example .env
ollama pull qwen2.5:7b
bash scripts/start.sh
```

Ollama должна быть запущена. Если команда `ollama` не установлена, установите её с официального сайта или выберите OpenAI в `.env`.

## Настройка моделей

Значения в `.env` задают исходную конфигурацию. Настройки, сохранённые через UI, могут иметь приоритет; проверьте страницу «Настройки» после изменения файла. Ключи вводятся только в `.env` и не отправляются из браузера.

| Режим | `.env` | Что требуется |
| --- | --- | --- |
| Полностью локальный | `TRANSCRIPTION_PROVIDER=local`, `ANALYSIS_PROVIDER=ollama` | Скачанные Whisper и Ollama-модели, CPU/RAM; платный API не нужен |
| Локальная речь + облачный анализ | `TRANSCRIPTION_PROVIDER=local`, `ANALYSIS_PROVIDER=openai` | `OPENAI_API_KEY`, доступ к OpenAI API |
| Облачные речь и анализ | `TRANSCRIPTION_PROVIDER=openai`, `ANALYSIS_PROVIDER=openai` | Ключ OpenAI, оплачиваемые API-запросы |
| Базовый отбор без LLM | `ANALYSIS_PROVIDER=heuristic` | Whisper по-прежнему нужен; эвристики не понимают контекст и уступают семантическому анализу |

`WHISPER_MODEL=tiny` или `base` ускоряет первый тест ценой точности; `small` — исходный компромисс. `OLLAMA_MODEL` должен совпадать с названием модели в `ollama list`. Ошибка AI отображается как ошибка задания; приложение не подставляет выдуманную транскрипцию или незаметно переключается на эвристики.

Для `.env` доступны `DATA_DIR`, `HOST`, `PORT`, `MAX_UPLOAD_GB`, `MAX_CLIPS`, `RETENTION_DAYS`, `FFMPEG_THREADS`, `TRANSCRIPTION_PROVIDER`, `WHISPER_MODEL`, `ANALYSIS_PROVIDER`, `OLLAMA_BASE_URL`, `OLLAMA_MODEL`, `OPENAI_API_KEY`, `OPENAI_MODEL`. Полный шаблон — [.env.example](.env.example).

## Хранение и эксплуатация

По умолчанию данные находятся в `data/`: база, исходники, аудио, транскрипты и клипы. Сохраняйте резервную копию каталога целиком, остановив воркер и API на время копирования. Не запускайте несколько воркеров для одной базы: файл `worker.lock` защищает единственный активный процесс.

Воркер выполняет очистку при старте и затем примерно каждый час: исходники завершённых/неудачных проектов старше `RETENTION_DAYS` удаляются вместе с временным аудио. Ручная очистка доступна в настройках. **После удаления исходника повторный монтаж и экспорт невозможны**, но ранее созданные MP4 остаются доступными. Удаление проекта удаляет его связанные файлы.

Для использования без Vite соберите frontend и запустите API и воркер:

```powershell
npm.cmd --prefix frontend run build
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
# В другом терминале:
.\.venv\Scripts\python.exe -m backend.app.worker
```

FastAPI раздаёт `frontend/dist`, если сборка существует. Для разработки предпочтителен Vite с автоматическим обновлением.

Приложение рассчитано на локальный доверенный доступ, **не имеет авторизации**. Не выставляйте порт наружу. Перед публичным развёртыванием нужны аккаунты, разграничение файлов, HTTPS, ограничения задач/диска, защита от злоупотреблений и отдельные воркеры.

## Проверки

Из корня проекта после установки зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
npm.cmd --prefix frontend run build
```

`GET /api/health` проверяет доступность API. Для проверки всей цепочки загрузите короткую запись с речью, дождитесь готового клипа, воспроизведите MP4 и экспортируйте его после правки. Это дополнительно проверяет реальные модели, FFmpeg и выбранные API; один открытый порт не доказывает работоспособность AI.

Автоматические тесты отдельных адаптеров могут подменять ответы внешних API. Они не доказывают качество реальной транскрипции или рейтинга. Конкретные результаты проверки текущей сборки указаны в отчёте о выполнении, а не предполагаются этой инструкцией.

При подготовке этой сборки облачная среда вернула HTTP 403 на загрузку модели с Hugging Face. Поэтому реальное локальное распознавание и полная AI-цепочка в этой среде пока не подтверждены. Для их проверки требуется разрешить загрузку модели через штатные сетевые настройки либо выбрать доступный облачный API с собственным ключом. Это ограничение не означает, что модель установлена или что тест адаптера проверил её качество.

Проверен Bash-launcher на отдельной пустой базе: запуск API, воркера и Vite; ответы `200` на health и список проектов напрямую и через Vite-прокси; остановка всех запущенных им сервисов. Это проверка запуска, не качества AI. Windows/PowerShell-запуск в Linux-среде не выполнялся.

## Проверка распознавания речи

Если Whisper не запускается, дважды щёлкните **`Проверить распознавание.cmd`**. Сценарий проверяет нативные библиотеки, загружает выбранную модель и проверяет запуск VAD. Для настоящей проверки речи перетащите короткий видеофайл на этот CMD. Текст транскрипции не выводится; в конце показываются количество слов или конкретная безопасная ошибка. Первая загрузка весов может занимать несколько минут.

Для первого теста выберите `base` и язык записи в настройках. `large-v3` скачивает несколько ГБ и требует значительно больше ресурсов; ошибка на `base` тоже требует диагностики, а не дальнейшей смены моделей наугад. Новые ошибки различают загрузку модели и само распознавание, включая HTTP/TLS, диск, память, права, длину Windows-пути, CUDA и нативные DLL. Класс исключения можно скопировать для диагностики; ключи и подписанные ссылки не включаются.

На Windows нативные CTranslate2/ONNX Runtime могут требовать Microsoft Visual C++ Redistributable x64. Новый launcher проверяет импорты и при подтверждённой ошибке загрузки DLL пробует установить официальный пакет через winget; если ошибка остаётся, запуск останавливается с сообщением. Это не означает, что любая ошибка Whisper вызвана Visual C++.

При обновлении существующей установки сначала остановите приложение (`Ctrl+C`), сделайте резервную копию `.env` и `data`, затем скопируйте файлы новой версии поверх старой. Не заменяйте `.env` файлом `.env.example` и не удаляйте `data`. Запустите кнопку запуска, затем повторите неудачное задание. Полный новый ZIP также можно распаковать в отдельную папку для независимой проверки; настройки и проекты при этом сами не переносятся.

## Частые проблемы

- **FFmpeg/FFprobe не найдены:** проверьте `PATH`, откройте новый терминал после установки. Нужна сборка с `libass` для вшитых субтитров.
- **Не удалось загрузить Whisper:** проверьте доступ к Hugging Face и место на диске. Не отключайте TLS-проверку. В ограниченной облачной среде потребуются разрешённые домены загрузки моделей.
- **Ollama недоступна / модель не найдена:** запустите Ollama, выполните `ollama list`, загрузите выбранную модель. Из Docker адрес `127.0.0.1` означал бы контейнер; этот проект по умолчанию запускается без Docker.
- **Ошибка OpenAI:** проверьте наличие ключа в `.env`, оплату, доступ к выбранной модели и сеть. Никому не отправляйте содержимое `.env` или ключ в тексте ошибки.
- **Импорт по ссылке не работает:** запись может требовать входа, cookies, доступ по региону или изменение экстрактора YouTube/Twitch. Используйте разрешённый локальный файл. Прямые эфиры, DRM и обход ограничений не поддерживаются.
- **Задание остановилось:** проверьте `.logs/worker.log` и запущен ли воркер. После устранения ошибки повторите задание через UI; если воркер прерван, перезапустите его.
- **Очень медленно:** начните с короткого файла, `WHISPER_MODEL=base` и 2–3 клипов. Не увеличивайте параллелизм без учёта памяти; 1080×1920 кодирование тоже требует CPU.

## Стоимость и развитие

Локальные Whisper/Ollama/FFmpeg не требуют оплаты за запросы, но используют ваше оборудование, электричество и диск. Облачные вычисления и хранение оплачиваются отдельно. Иллюстративный бюджет платных AI — **$0,4–1,5 за час речи**; это не актуальная котировка провайдера. Формула и границы оценки описаны в архитектуре. Сверяйте текущие тарифы перед массовой обработкой.

Дальнейшие этапы: калибровка качества на ваших стримах, улучшение слежения за лицом и анализа сцен, затем многопользовательский продукт с PostgreSQL, S3 и очередью Redis/Celery.
